📅 B 路线 · 分月详细计划

🔹 第 1–2 月：Python + 数据底座

目标：把数据变成 ndarray/DataFrame 并做完清洗与可视化；实验可脚本化复现

第1–3周：Python 工程化（有 JS 可压缩）

  • 语法对照 JS：推导式、字典/集合、函数、异常、pathlib、venv
  • 工程：argparse / 日志 / 配置 JSON、类型标注入门
  • OOP 够用即可：类、dataclass、简单继承——不啃设计模式大全
  • 实战 数据目录批处理 CLI：读 csv/json → 校验 → 汇总报告
  • 可跳过 若已完成仓库 Day01–04，本段以「补 OOP + 测试习惯」为主

第4–6周：NumPy

  • ndarray、广播、索引、reshape、向量化（少写 Python for）
  • 线性代数接口：dot、matmul、linalg（先会用，推导放第 3 月）
  • 实战 纯 NumPy 实现线性回归（梯度下降），画 loss 曲线 [参考]

第7–8周：Pandas + 可视化

  • DataFrame 选择/过滤/groupby/merge、缺失值、类别编码直觉
  • matplotlib / seaborn：分布、相关、混淆矩阵以后会反复用
  • 实战 Titanic 或自选 CSV 完整 EDA 报告（Jupyter 或脚本 + 图） [Kaggle Learn]

🔹 第 3–4 月：数学直觉 + 经典 ML

目标：公式能翻译成代码；能独立跑完「数据→特征→训练→评估」闭环

第9–11周：数学（直觉优先）

  • 视频 3Blue1Brown 线代：向量、矩阵乘法、特征值直觉 [B站]
  • 视频 3Blue1Brown 微积分：导数、梯度、链式法则 [B站]
  • 概率：条件概率、贝叶斯、期望方差、正态分布、似然直觉
  • 标准 不背证明；卡壳时「打开 3B1B / 用 NumPy 验算」即可

第12–16周：机器学习核心

  • 监督 / 无监督概念；训练集·验证·测试；过拟合与正则（L1/L2）
  • 线回归、逻辑回归、树模型（GBDT 概念级）、K-Means
  • 评估：Accuracy / Precision / Recall / F1 / ROC-AUC、混淆矩阵
  • Pipeline：缺失值处理、StandardScaler、交叉验证、学习曲线
  • 实战 sklearn 在 2–3 个数据集上对比模型；⭐ 垃圾邮件或新闻分类全流程
  • 主课：Andrew Ng ML Specialization（可跟 B 站）

🔹 第 5–7 月：深度学习 + PyTorch

目标：手写训练循环；理解反传与优化器；CNN/序列模型会改会训

第17–20周：神经网络基础

  • MLP、激活函数、交叉熵；Batch / Epoch / LR
  • 反向传播直觉；SGD → Momentum → Adam
  • 实战 micrograd 或自写小自动求导；NumPy 两层网打 MNIST 子集 [micrograd] [nn-zero-to-hero]

第21–24周：PyTorch 熟练

  • Tensor、autograd、nn.Module、Dataset/DataLoader
  • 标准训练循环：zero_grad → forward → loss → backward → step
  • 保存 checkpoint、TensorBoard / 简单日志
  • 实战 CNN 打 MNIST/CIFAR；文本分类（Embedding + RNN/LSTM 或短 Transformer）
  • 教材：PyTorch Tutorials | 李沐 d2l（选章）| fast.ai（可并行）

第25–28周：CNN / 正则 / 迁移学习

  • 卷积、ResNet 跳跃连接直觉；数据增强、Dropout、BN、Early Stopping
  • 迁移学习：冻骨干 + 换头微调；学习率调度
  • 实战 小图像分类项目：预训练 backbone + 自己的数据集（或公开子集）

🔹 第 8–10 月：Transformer + 微调

目标：讲清 Attention；能跑通一次指令微调并做基础评测

第29–32周：Transformer / LLM 原理

  • Self-Attention、Multi-Head、位置编码；Encoder vs Decoder-only
  • Tokenizer（BPE）、预训练目标直觉、Scaling 粗概念
  • 实战 跟完 nanoGPT 或自写迷你 GPT 做字符级生成 [nanoGPT]
  • 阅读：Illustrated Transformer | 李宏毅 GenAI

第33–36周：Hugging Face + LoRA 微调

  • transformers：Tokenizer / Model / Trainer 或自定义 loop
  • PEFT / LoRA：秩、可训参数量、显存粗估；指令数据格式
  • 评测：hold-out 集、简单自动指标 + 人工抽检（别只报 train loss）
  • 实战 用 LLaMA-Factory 或 PEFT 对小模型做一次领域微调（云 GPU / 消费级卡量力而行）
  • 不做 从零预训练大模型、全参微调 70B

第37–40周：推理与服务化入门

  • batch、量化（bitsandbytes / GPTQ 概念）、延迟与吞吐
  • 推理框架扫盲：vLLM / TGI 知道解决什么问题即可
  • 用 FastAPI 包一层「加载本地/微调模型 → 预测接口」（复用你已有 FastAPI）
  • 实战 模型文件 + 推理 API + 简单 Gradio Demo

🔹 第 11–12 月：毕业项目 + 面试

目标：1 个可深挖的训推项目写进简历；能讲清实验设计

第41–44周：毕业项目（二选一做深）

  • 项目 A 端到端分类/检测小系统：数据管道 + 训练脚本 + 指标看板 + 推理 API
  • 项目 B 领域小模型 LoRA：数据构建 → 微调 → 评测表 → Demo；写清失败案例
  • 硬性交付：README、架构/实验记录、可复现命令、Demo 视频

第45–48周：面试与补强

  • 题库：损失函数、优化器、过拟合、BN/Dropout、Attention、训练不稳定排查
  • 项目深挖：为什么这组超参、如何防泄漏、线上会怎么监控
  • 选修补课 轻量 RAG/Agent——只为懂业务协作，不做成 A 路线第二主线
  • 简历口径：「前端工程化 + 能独立完成训练/评估/部署小闭环」

⚠️ B 路线常见误区

坑1：先啃完教材再写代码。实验驱动：先跑通，再补卡住的数学。
坑2：和 A 路线双主线并行。RAG/Agent 很香，但会挤掉训练深度。B 主线时应用最多当「周末补课」。
坑3：只调 Trainer / 一键微调，讲不清 loss 与数据。面试必挂。至少手写过一次完整训练循环。
坑4：只报训练集准确率。验证集、过拟合、错误案例分析才是 MLE 语言。
坑5：放弃前端。Gradio/简单 UI + 清晰实验图表，是工程向 MLE 的加分项，不是分心。
和旧版 deep-plan 的差别：旧版名义「A」却塞满 ML，又在坑里写「99% 岗不用训练」——自相矛盾。本版明确：你要走 B，训练与评估就是主业；应用开发请看 ai-career-plan.html。
