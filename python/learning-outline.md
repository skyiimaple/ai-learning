## 每日原则（每日出计划时遵守）

1. **并块不并线**：同一天只并「同一能力链」上的 2–3 点（如 Rewrite+Hybrid+Rerank），不跨 RAG/Agent/部署硬拼。  
2. **产出优先**：当天没有可运行产物 / 可展示数字 / 可口述关卡 → 计划不合格。  
3. **框架克制**：Chroma 够用不上 pgvector；手写 Agent 循环够用不上重型框架；需要时再换。  
4. **说「放慢」**：下一日起拆回更细的 Day，本大纲后移。  
5. **周考**：可改为每完成上表一个「月关卡」做一次小测，不强制每周拖一天。
