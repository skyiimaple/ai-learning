# ai-learning 网站实现计划

目标：在 web/ 中使用 VitePress 搭建本地可运行、可构建的文档网站，按 agent、python、node 实际目录组织；不增加视频栏目。

设计：原始讲义是唯一内容源。构建脚本只读取三个目录中的 Markdown（排除依赖、隐藏文件、缓存），在 web/.generated 生成页面与目录索引。README 映射为目录首页；保留其他文档文件路径和标题。已有 Python HTML 资料以明确白名单复制，原样提供访问。首页展示三个目录及真实内容，文档页使用 VitePress 导航、中文本地搜索、目录、前后篇和深浅色主题。

技术：VitePress 1.6.4、Vue 3、Node.js 原生脚本及 node:test。所有新增实现文件都位于 web/；不移动原始内容、不改进度、不提交 Git、不调用学习项目的模型服务。
