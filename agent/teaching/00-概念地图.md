## Agent 是什么

在目标驱动下，模型反复：理解现状 → 选动作（常是调工具）→ 看结果 → 直到能交付。

不是「更聪明的聊天」，而是「带行动能力的决策循环」。

## 和相近概念对照

| 概念 | 做什么 | 有没有行动 |
|------|--------|------------|
| Chat / 补全 | 根据上下文生成文本 | 无 |
| RAG | 先检索再答 | 只读知识，通常单轮 |
| Tool calling | 模型可发起一次或几次函数调用 | 有，但常是「调用完就答」 |
| Agent | 多步循环，自己决定何时停 | 有，且会根据观察继续 |

## 三个核心零件

1. **模型（大脑）**：推理、选工具、组织最终回答
2. **工具（手脚）**：你写的函数 / API（查库、搜网页、改状态）
3. **运行时（骨架）**：拼消息、执行工具、把结果塞回对话、控循环与停止

## 一条消息流（心智模型）

用户 → 运行时组上下文 → 模型 →（可选）`tool_calls` → 运行时执行 → observation 回填 → 模型再想 → … → 最终自然语言答用户

## 前端背景可复用的直觉

- 工具 ≈ 后端 API
- 消息列表 ≈ 请求链路里的 log
- Agent loop ≈ 带终止条件的 `while` + 异步副作用
